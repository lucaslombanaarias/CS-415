# CS 415
Coursework for CS 415 (Game Development) at UIUC by Lucas Lombana Arias

MP1: Infinite Matrix, a Matrix-themed tunnel runner in Unreal Engine 5.6 Blueprints that builds on the Kodeco tutorial with health, score, health packs, projectiles, enemies and increasing speed, plus two creative mods: tunnel colors that follow the player's health and a saved high score.

Unreal assets are stored with Git LFS, so run `git lfs pull` after cloning.
